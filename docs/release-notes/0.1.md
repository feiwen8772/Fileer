# Fileer v0.1

Fileer 的首个独立版本，基于 Strata 开发。需要 Apple silicon Mac 和 macOS 26 或更新版本。

- 新的 Fileer 名称与应用图标。
- 可创建、重命名和删除侧栏空间，支持自定义分类、固定项目和分类排序。
- Finder 风格的分组与文件排序，适用于列表和分栏视图。
- 应用内网络浏览与隔空投送发送页面。
- 16 点间距的空间切换圆点，点击即可切换空间。
- 使用 Fileer 仓库独立分发并验证签名更新。

本版本按项目所有者授权，以未公证测试版发布，尚未经过 Apple Developer ID 签名和 Apple 公证。macOS 可能阻止首次打开。
更新归档与更新源使用 Fileer 自有 EdDSA 密钥签名；应用不再检查原 Strata 项目的更新。
